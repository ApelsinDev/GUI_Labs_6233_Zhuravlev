# Лабораторная работа № 1

Приложение с надписью и кнопкой. Первое нажатие показывает картинку, второе возвращает текст. 

## Технологии

Python и PyQt5. Оформление — QSS. Разработка — Visual Studio Code.

## Запуск

Нужен установленный Python. Команды для запуска в терминале PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если окружение уже создано и PyQt5 установлен, достаточно последней команды.
