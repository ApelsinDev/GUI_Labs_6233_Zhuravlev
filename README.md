# Лабораторные работы по PyQt5

Каждая работа находится в своей папке. Для всех работ используются общее окружение Python и зависимости.

| Папка | Работа |
| --- | --- |
| `lr1` | Окно с переключением текста и изображения |
| `lr2` | «Термостанция»: связанные поля температуры, сигналы и слоты |
| `lr3` | «Киноархив»: работа с SQLite, вывод таблиц и выполнение SQL-запросов |

Описание и скриншоты каждой работы находятся в README внутри её папки.

## Подготовка на Windows

Откройте корневую папку проекта в VS Code. Если окружения ещё нет, создайте его в терминале PowerShell:

```powershell
py -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Через **Ctrl+Shift+P → Python: Select Interpreter** выберите `.venv\Scripts\python.exe`.

## Запуск

Первая лабораторная:

```powershell
.\.venv\Scripts\python.exe lr1/main.py
```

Вторая лабораторная:

```powershell
.\.venv\Scripts\python.exe lr2/main.py
```

Третья лабораторная:

```powershell
.\.venv\Scripts\python.exe lr3/main.py
```

В «Киноархиве» нажмите **«Демо»**, чтобы открыть готовую базу фильмов. Для выбора другой SQLite-базы используйте **«Открыть БД»** или меню **База данных → Set connection**.

В `.vscode/launch.json` предусмотрены отдельные конфигурации запуска для трёх работ.
